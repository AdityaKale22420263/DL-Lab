# Deep Learning Assignments

This repository contains a collection of deep learning assignments implemented using **Python, TensorFlow/Keras, OpenCV, and NLP techniques**.  
Each assignment folder includes:
- Source code (Jupyter Notebook / Python scripts)
- Dataset or sample input files
- Pre-trained model files (if applicable)
- Report (DOCX) explaining theory, methodology, and results
- Output screenshots/results


---

## 📘 Assignments Overview

1. **Feedforward Neural Networks**  
   - Implemented in Python using TensorFlow/Keras  
   - Covers basic ANN architecture, activation functions, and training  

2. **Facial Recognition using OpenCV + Deep Learning**  
   - Uses OpenCV for preprocessing  
   - Binary classification (face match / not match)  

3. **Image Classification with CNN**  
   - Convolutional Neural Network for multi-class classification  
   - Includes training, evaluation, and visualization  

4. **Time Series Prediction with RNN**  
   - Uses RNNs for forecasting (stock prices, weather, etc.)  

5. **Text Identification using OpenCV + Tesseract OCR + DNN**  
   - Preprocessing images with OpenCV  
   - Extracting text with Tesseract OCR  
   - Enhancement with DNN models  

6. **Sentiment Analysis using LSTM / GRU**  
   - NLP-based model for text classification  
   - Uses word embeddings + RNN variants  

7. **Object Detection using YOLO + Pretrained Model**  
   - YOLO-based object detection  
   - Pretrained weights used for detecting common objects in images/videos

##  Usage

1. Clone the repository:
   ```bash
   git clone https://github.com/AdityaKale22420263/DL-Lab.git
   cd DL-lab
   ```

2. Navigate to the desired assignment folder:
   ```bash
   cd DL_Assignment2
   ```

3. Open the notebook or run Python scripts:
   ```bash
   jupyter notebook
   # OR
   python main.py
   ```
